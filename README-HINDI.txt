PRINCE JARVIS — Android starter project (v0.1)

Is project mein abhi push-to-talk Hindi speech recognition, Hindi Text-to-Speech,
YouTube/Chrome launch, flashlight toggle, media volume raise aur phone dialer
open karne ke basic demos hain.

IMPORTANT:
- Yeh APK abhi build/test nahi hua hai. Motorola G05 par compatibility guaranteed nahi.
- "Hey Jarvis" always-on wake word, general AI chat aur WhatsApp auto-send abhi included nahi.
- Calls sirf Dialer kholti hain; app khud call nahi karti.
- Speech recognition Android ke configured speech service par depend karta hai.
- Microphone permission maangi jayegi.

PHONE SE GITHUB PAR UPLOAD:
1. github.com par login karein.
2. New repository banayein: PRINCE-JARVIS (Public ya Private).
3. Is ZIP ko phone mein extract karein.
4. Repository page > Add file > Upload files.
5. Extract kiye gaye folder ke ANDAR ki sab files/folders upload karein.
   .github folder bhi upload hona chahiye. Agar hidden folders file picker mein na dikhein,
   GitHub web editor se workflow file alag create karna padega.
6. Commit changes karein.
7. Repository > Actions > "Build PRINCE JARVIS APK" > Run workflow.
8. Build green ho jaaye to run ke neeche Artifacts mein
   PRINCE-JARVIS-debug-apk download karein. ZIP extract karke APK install karein.

Agar build fail ho, Actions ka red error screenshot bhejein. Password, OTP ya API key share na karein.
